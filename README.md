# dronesim
Browser-based drone flight simulator built with React &amp; Three.js — 6-DOF dynamics, PID flight controller, waypoint missions, sensor simulation, dual joystick control.
# 🚁 无人机操控与航线飞行模拟器 · Drone Flight Sim

一个纯浏览器端的无人机飞行模拟器，基于 **React 18 + Three.js + MUI** 构建。
无需安装、无需后端，**打开 HTML 即可体验**从手动摇杆操控到航点自主飞行的完整流程。

模拟器实现了六自由度刚体动力学、级联 PID 飞控、传感器噪声模型与实时三维可视化，
可用于飞控算法教学演示、PID 参数调参体验以及无人机操控训练入门。

## ✨ 功能特性

### 🎮 操控与视角
- **双虚拟摇杆**：左杆（油门 / 偏航）、右杆（俯仰 / 横滚），支持鼠标与触屏
- **键盘备用操控**：`W/S` 油门、`A/D` 偏航、方向键俯仰横滚、`空格` 回中、`R` 复位
- **两种相机模式**：
  - 地面观察者视角（站在地面仰视飞机，可环视）
  - 环绕跟随视角（第三人称自由旋转 / 缩放）
- **移动端横屏引导**：竖屏时自动提示旋转设备

### 🛩️ 飞行动力学
- **六自由度刚体模型**：位置、速度、姿态四元数、角速度（NED 坐标系）
- **电机推力模型**：四旋翼 X 型布局，单电机推力 / 反扭矩映射
- **气动阻力**：线性阻尼 + 角阻尼
- **RK4 积分器**：固定步长物理步进，帧率无关，稳定可靠
- **状态插值**：物理与渲染解耦，画面平滑

### 🎛️ 飞控算法
- **姿态环 PID**：Roll / Pitch / Yaw Rate 级联控制
- **GPS 位置环**：速度环 + 位置环 + 高度环，含前馈解耦
- **手动姿态模式**：仅姿态稳定，全手动油门
- **特技模式**：角速率直通
- **抗积分饱和 + 微分低通滤波**

### 🗺️ 航线与任务
- **可视化航点编辑**：在 2D 地形俯视图上点击添加航点，或直接输入 NED 坐标
- **自动巡航**：顺序到达航点，支持到达半径判定
- **手动接管**：自动飞行中推动摇杆即可无缝接管
- **实时任务进度显示**

### 📡 传感器与状态仿真
- IMU（加计 + 陀螺，含高斯噪声）
- GPS（位置 / 速度，10Hz，含卫星数与定位质量）
- 气压计（含噪声，按国际标准大气压模型）
- 磁力计（航向）
- 电池模型（电压随电量下降、电流消耗）
- 图传 / 遥控链路质量模型（随距离衰减）

### ⚙️ 参数在线调校
- 机体预设：默认 / 轻载 / 重载 / 高机动
- 质量、最大推力、重力、最大倾角、悬停油门
- 姿态 PID 参数（Kp / Ki / Kd）
- 偏航速率 PID 参数
- 航点到达半径
- **所有参数即时生效，无需刷新**

## 🚀 快速开始

### 方式一：在线玩（最简单）
直接打开 👉 **https://ermao-web.github.io/dronesim/**

### 方式二：下载本地打开
1. 下载仓库里的 `index.html`
2. 用现代浏览器（Chrome / Edge / Firefox / Safari）直接打开
3. **全部依赖已内联，无需联网、无需构建**

### 方式三：本地服务（若浏览器限制 file:// 访问）
```bash
# 在文件所在目录执行
python -m http.server 8080
# 然后访问 http://localhost:8080/drone-sim-standalone.html
```

### 🐞 调试模式
在 URL 后追加 `?debug=1`，可在浏览器控制台通过 `window.__DRONE__` 访问仿真引擎实例：

```
http://localhost:8080/drone-sim-standalone.html?debug=1
```

## 🧠 技术实现概要

```
┌─────────────────────────────────────────────────┐
│  UI 层（React + MUI）                            │
│  顶部状态栏 / 摇杆 / 抽屉面板                     │
└────────────────┬────────────────────────────────┘
                 │ useSyncExternalStore（10~30Hz 节流）
┌────────────────▼────────────────────────────────┐
│  仿真引擎（固定步长 1/240 s，RK4）                │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 动力学    │→│ 传感器    │→│ 飞控 PID │       │
│  │ 6-DOF    │  │ 噪声模型  │  │ 姿态/GPS │       │
│  └──────────┘  └──────────┘  └──────────┘       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 航点管理  │  │ 制导律    │  │ 电池/链路 │       │
│  └──────────┘  └──────────┘  └──────────┘       │
└────────────────┬────────────────────────────────┘
                 │ requestAnimationFrame
┌────────────────▼────────────────────────────────┐
│  渲染层（Three.js WebGL）                        │
│  场景 / 光照 / 阴影 / 无人机模型 / 航点标记        │
└─────────────────────────────────────────────────┘
```

- **物理与渲染解耦**：物理固定 240Hz 步进，渲染跟随刷新率，用累积器 + 状态插值保证平滑。
- **坐标系**：内部使用 NED（北-东-地），渲染时转换到 Three.js 的 Y-Up 右手系。
- **四元数姿态**：避免万向节锁，姿态解算使用四元数微分方程。
- **确定性仿真**：固定步长 RK4，相同输入下结果可复现。
